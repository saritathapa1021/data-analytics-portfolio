# Wine Quality Prediction Using Machine Learning

**Python | Scikit-Learn | Machine Learning | Neural Networks | PCA**

## Project Overview

This project explores the use of machine learning and neural networks to predict wine quality based on the physicochemical properties of white wine samples. Multiple classification models were evaluated and compared using cross-validation, hyperparameter tuning, and dimensionality reduction techniques.

The objective was to identify the model configuration that achieved the best predictive performance while understanding how different neural network architectures and parameters affect model accuracy.

---

## Business Problem

Wine quality is traditionally assessed through expert tasting, which can be subjective and time-consuming. By using measurable chemical characteristics of wine, machine learning models can help support quality control processes and provide consistent quality predictions.

---

## Dataset

**Dataset:** White Wine Quality Dataset

The dataset contains physicochemical measurements of white wine samples, including:

- Fixed Acidity
- Volatile Acidity
- Citric Acid
- Residual Sugar
- Chlorides
- Free Sulfur Dioxide
- Total Sulfur Dioxide
- Density
- pH
- Sulphates
- Alcohol

**Target Variable:**
- Wine Quality Classification
